                  How forgery detection works

                  The QR code holds the visit details (name, host, zones, valid times) plus a digital signature. The signature is made with a secret key that only this server has (for a temporary pass, the issuing officer's phone has its own key the server knows about), and it is mathematically tied to those exact details.

                  Every gate phone has the matching public key, which can check a signature but cannot create one. If anyone changes even one character, such as stretching the end time, the signature no longer matches and the phone refuses the pass, with no internet needed. Making a new valid signature would need the server's secret key.

                  "Copy tampered pass" makes exactly that kind of fake: it changes the end date and keeps the original signature, so you can show it being refused. An exact copy of a real pass is caught a different way: single-entry passes are blocked if already used, the ID check must match, and two gates admitting the same pass offline raises an alert when they sync.
